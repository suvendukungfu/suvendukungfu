## Boss Fight: Engineering Edition

| Target | Build strategy |
| --- | --- |
| **Unpredictable AI output** | Structured-output validation, defensive fallbacks, and evaluation tests |
| **Slow local inference** | Cold-versus-warm benchmarks and hardware-aware profiling |
| **Chaotic operational data** | Reproducible pipelines, reconciliation checks, and clear logs |
| **Prototype-to-product gap** | Clear service boundaries, useful observability, and build-time verification |

<p align="center"><em>The target is progress, not a made-up high score. Measure the result, learn from the miss, and change the angle.</em></p>

<details>
  <summary><strong>How the battle animation works</strong></summary>

  1. GitHub Actions generates light- and dark-mode contribution grids from the profile's real activity.
  2. The repository's SVG overlay script expands the graphic into a small game scene with an animated flight path, bird, slingshot, fort materials, targets, and impact effects.
  3. The generated SVGs are published to the `output` branch and refreshed on a schedule or after changes on `main`.

  To refresh manually, open the workflow above and select **Run workflow** on `main`. The latest visual appears after the workflow finishes successfully.
</details>
