## 🏰 Boss Fight: Engineering Edition

| Boss | Power-up / strategy |
| --- | --- |
| **Unpredictable AI output** | 🔥 Validate structured outputs, build fallbacks, and test edge cases |
| **Slow local inference** | ⚡ Benchmark cold and warm runs; understand model and hardware trade-offs |
| **Chaotic operational data** | 🧩 Make pipelines reproducible and add reconciliation checks |
| **Prototype that won't scale** | 🛠️ Improve service boundaries, observability, and build-time verification |

  <summary><strong>How the graph game works</strong></summary>

  - The contribution grid is generated from the real profile activity.
  - A repository-owned script adds an original animated bird, curved flight path, slingshot, and small target fort.
  - GitHub Actions publishes the light- and dark-mode SVGs to the `output` branch on a schedule or after a push to `main`.

  The workflow must complete successfully for the latest theme to appear. To refresh manually, open the workflow above and select **Run workflow** on `main`.
